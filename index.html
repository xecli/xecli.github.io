Flagship project

XeCLI — terminal-first Xbox 360 toolkit

A terminal-first toolkit with command-line and desktop interfaces for RGH/JTAG consoles: link over XBDM, JRPC2, and FTP, dump and inspect XEX executables, inspect memory, run diagnostics, and automate repeatable console workflows.

Console link

Connect to RGH/JTAG consoles over XBDM, JRPC2, and FTP from one client.

XEX tooling

Dump, inspect, and work with XEX executables and loaded modules.

Memory & diagnostics

Peek and poke memory, and run transport, memory, and storage health checks.

Automation

Script repeatable console workflows and diagnostics straight from the terminal.
