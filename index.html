XeCLI

A Windows toolkit for Xbox 360 RGH/JTAG consoles. Use rgh.exe from the command line or XeTerminal on the desktop to connect to a console, inspect executables and memory, move files and run diagnostics.

Download Documentation Source

What it does

Connect
Talks to RGH/JTAG consoles over XBDM, JRPC2 and FTP.
Executables
Dumps and inspects XEX files and loaded modules.
Memory
Reads and writes console memory, with breakpoint watching.
Files
Browses and transfers files on the console's drives.
Diagnostics
Checks transport, memory and storage health.
Scripting
Every command runs from PowerShell or a batch file.
rgh start
rgh status
rgh modules list
rgh screenshot --out .\capture.png

Windows 10 or 11, x64. Full command reference in the wiki.

Other tools

  • Xtaf-CLI C#

    Mounts and recovers Xbox 360 FATX, STFS and GDFX images.

  • x360controller Python

    Controller bridge between Windows, Android and RGH/JTAG consoles.

  • XeCLI-XellFetch PowerShell

    XeLL payload that pulls NAND and keyvault data from a console over the network.

  • xenon-soft3d C, libXenon

    Software 3D rasterizer for Xbox 360 homebrew, drawing to the Xenos tiled framebuffer.

  • xenasm Python, alpha

    Builds and decodes Xenos GPU shader microcode. Output is checked against Xenia.
